========================================
Ticker API 명세서 - 노션에 넣는 방법
========================================

【 방법 1: CSV 임포트 (권장) 】
1. 노션 왼쪽 사이드바 맨 아래 "설정 및 멤버" 클릭
2. 아래쪽 "가져오기(Import)" 클릭
3. "CSV" 선택
4. API-SPEC-NOTION-DB.csv 파일 선택 → 열기
5. 새 데이터베이스가 자동 생성됨

【 방법 2: 페이지에서 임포트 】
1. 노션 페이지 열기
2. 우측 상단 "..." (점 3개) 클릭
3. "가져오기" → "CSV" 선택
4. API-SPEC-NOTION-DB.csv 파일 업로드

【 방법 3: 기존 테이블에 병합 】
1. 이미 만든 테이블/데이터베이스 열기
2. 우측 상단 "..." → "CSV와 병합(Merge with CSV)"
3. API-SPEC-NOTION-DB.csv 선택
